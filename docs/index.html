01 / CONNECT

Run the audit on your computer

This website connects to a local Python runner. Audits and reports stay on your computer. GitHub Pages alone cannot run Python or control Chrome.

First-time setup · Python 3.11+ and Chrome
  1. Download the project and unzip it.
  2. Open a terminal in its folder. Run:
    python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python runner.py
    Windows: use py instead of python3 and .venv\Scripts\activate.
  3. Paste the pairing code below. Allow local network access if Chrome asks. A separate audit Chrome profile will open when you start.

If your browser blocks the connection, use the same interface locally. No security settings need to be disabled.

Runner not connected. Start the Python runner, then paste its pairing code and click Connect runner.

02 / AUDIT

Choose your stores and keyword

Fields marked * are required. Business name, address, phone and branding are optional.

Store latitude and longitude are detected automatically from the resolved GBP pin and used as the keyword search centre. A map viewport is never treated as the business pin.

Optional fallback if the store pin cannot be resolved

One row per store and keyword. Required: store_code, maps_url, keyword. Recommended: business name, expected address, phone; coordinates are detected automatically. Maximum 100 rows / 3.5 MB file. File and logo together must fit within the 5 MB request limit.
